## D-022 (Phases 5-7 build, synthetic-tested only)
- Phase 5-7 code written and tested on synthetic fixtures only (src/tests/test_phase567.py). It has NOT been run on real data: the pilot has no AI labels, no Phase 3/4 freeze and ~7 usable deals, so all three phases refuse or return NOT ASSESSABLE.
- Phase 6 evidence classification is rule-based with a fixed priority order (07_robustness.py). "NOT ASSESSABLE" is an added status (power gate: strict AI N >= 30, total N >= 100) because forcing one of the eight labels on an underpowered sample would be fabrication.
- The 12 formal checks are: broad AI, winsorised outcome, trimmed, exclude quality C, exclude semiconductors, exclude EV/Rev>100x, exclude stale financials, median regression, CEM, PSM, leave-one-sector-out worst case, leave-one-year-out worst case. EV/EBITDA is a secondary outcome, not one of the 12.
- Wild-cluster bootstrap (year, sector) is reported as supplementary and flagged unreliable below 10 clusters; it is not part of the classification rule.
- Sector-year benchmark in Phase 7 falls back to an IN-SAMPLE non-AI median when no external benchmark file exists; it is labelled as such.
- Residual case-study context (buyer rationale etc.) is NOT auto-filled; it requires manual public-source review.

## D-023 (Lite public study, 2026-10-13)
- Route chosen by user: "Lite public study". 47 additional US public technology targets (2015-2025) were researched by parallel agents using SEC filings/press releases (WebSearch/WebFetch only), 8 agents x 6 deals, loaded via data_raw/lite_deals.json (source_universe = lite_hand_selected_pilot_NOT_SYSTEMATIC). Combined with the 8 pilot deals: 55 deals; Phase 2 gives EV/Revenue N=35, EV/EBITDA N=17, premium N=20.
- The deal list was chosen by hand from memory of well-known take-privates/strategic deals: selection bias (survivorship toward large, well-covered deals) is built in. This is NOT a systematic universe.
- Agent-reported caveats (see notes column per deal): many unaffected prices not found (premium N is small); equity vs EV often unlabeled (EV left null unless company-stated or bridgeable); several descriptions are verbatim fragments (fetch tool quote cap); some close dates inferred; L47 Pluralsight not collected (empty stub dropped); Momentive announcement date 2023-03-13; Avalara offer 93.50; Marketo 35.25; Apptio 38.00; Cvent 36.00.
- Because only 18 pooled rows need AI coding (candidates + audit sample), two coders can finish in ~30-45 min each (src/03a2_coder_xlsx.py). Expected strict-AI N is far below the Phase 6 power gate (30), so Phase 6 will return NOT ASSESSABLE; gates are NOT being lowered.
