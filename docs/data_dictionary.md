# Data Dictionary (Phase 2)

Generated by `src/data_dictionary_spec.py`; do not edit by hand. Every column of `deals_stage2.csv` and `financials_stage2.csv` is covered (enforced by `src/tests/test_pipeline.py`).

**Missingness codes** (stored in `<field>_missing_code` columns; the numeric field itself is NULL): `NA` not applicable, `ND` not disclosed, `NF` not found after search, `NR` not reliable enough. No missing value is imputed.

**Final `ai_flag`, `ai_intensity`, `ai_subsector` do not exist in Phase 2** (created in Phase 3 only). `ai_candidate_flag` is a keyword screen.
